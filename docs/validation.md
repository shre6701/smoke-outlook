# Validation: hindcasts of the 2024 and 2025 seasons

Generated by `uv run python -m sim.validate`. One run per day at 12:00 UTC, 1 Oct – 30 Nov (2024: 61 runs, 2025: 61 runs), each using only weather forecasts and fires published before the run.

**Scope note (15 Nov 2026).** The project is now India-centric: receptors are Indian cities only. The Lahore rows were removed from this report by hand; every remaining number is unchanged from the original runs. Fires in Pakistan are still simulated as sources.

**Read this first.** The model gives fire smoke only. Stations measure PM2.5 from all sources. A good score here means simulated smoke arrives when measured PM2.5 goes up; it does not mean the simulated amount is right. All simulated values are labelled simulated. Days are not independent, so ranges come from a 5-day block bootstrap.

## Smoke source ledger: how much a share moves

For the same 24 hours, the share of an Indian city's simulated fire smoke that comes from fires in Pakistan (the only neighbouring country inside the v1 domain; the rest is from Indian states and disputed areas) is computed twice: by the run of that day and by the run one day earlier. The difference is a measure of forecast uncertainty in the ledger. Shares do not depend on the emission scale.

## Limits

- Archive weather is stored every 3 hours (the live system uses every hour).
- Archive fires are the reprocessed FIRMS product with an assumed 3-hour delay; the live feed of the day may have differed slightly.
- Two seasons, one run per day, three cities, all in the north. Shares from fires abroad cannot be checked against stations in the source area.
- Scores for one city-season rest on about 60 days that are not independent.
- Measured PM2.5 includes fireworks (Diwali: 31 Oct – 1 Nov 2024, 20–21 Oct 2025), traffic, industry and dust. None of these are in the model.
- Sources: OpenAQ (CPCB, US diplomatic posts via AirNow, low-cost networks); India Air Quality Database, XKDR Forum (CPCB, CC BY 4.0); NASA FIRMS; NOAA GFS; CAMS via Open-Meteo.
